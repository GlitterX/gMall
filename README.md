# gMall

gMall 是一个 `B2B2C + S2B2C` 平台型电商系统，首期围绕 `平台、供应商、商家、消费者` 四类核心角色，交付 `管理后台 + UniApp（H5/小程序） + PC 展示端`，聚焦 `实物商品 + 快递发货` 的主交易闭环。

## Highlights

- 面向平台治理、供应商供货与直营、商家经营、消费者购物的一体化商城模型
- 支持 `B2B2C + S2B2C` 双经营模式，覆盖平台、供应商、商家多方协同
- 首期围绕“入驻 -> 经营 -> 店铺展示 -> 下单 -> 支付 -> 履约 -> 结算”建立核心闭环
- 同时覆盖管理后台、移动端与 PC 展示端，并保留稳定的多语言扩展位
- 采用“必须双语录入 / 必须双语展示 / 允许回退展示”策略，统一回退 `en-US -> zh-CN`

## Overview

gMall 的目标不是一次性铺满所有商城能力，而是优先打通首期最关键的业务主链路：平台招商与组织治理、供应商供货与直营、商家经营与店铺管理、消费者浏览加购与按卖家分组下单，以及后续支付、履约、售后、结算的衔接能力。

在产品边界上，gMall 将 `Storefront` 作为统一展示与装修承载对象，支撑平台首页、专题页、店铺首页等核心场景；在业务边界上，重点处理供应商“既可供货也可直营”的双角色经营模式，并为多语言和多端展示保留稳定扩展位。
